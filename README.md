# 조각글 · 비밀번호 잠금 버전

## 이번 버전에서 변경된 사항
- 사이트 주소를 열면 **비밀번호 입력 화면**부터 표시됩니다.
- 정확한 비밀번호를 입력하면 7일간 유효한 서명된 HttpOnly 쿠키가 발급됩니다.
- 인증 전에는 메인 앱이 열리지 않도록 Vercel Routing Middleware에서 차단합니다.
- Gemini 생성 API도 서버에서 인증 쿠키를 별도로 검사합니다.
- 사이드바 하단 **잠금 / 로그아웃**을 누르면 쿠키가 삭제되고 비밀번호 화면으로 이동합니다.
- 기존 대화 / 프롬프트 / JSON 백업 기능은 그대로입니다. 기존 사이트와 **같은 주소로 업데이트하면** 브라우저 기록이 유지됩니다.

## Vercel 배포 방법
1. ZIP을 압축 해제하고 **모든 파일과 `api/` 폴더를 그대로** GitHub에 올립니다. `middleware.js`, `login.html`, `api/login.js`, `api/logout.js`가 반드시 포함되어야 합니다.
2. Vercel에서 Framework Preset은 Other, Root Directory는 `./`을 사용합니다.
3. Vercel → Settings → Environment Variables:
   - `GEMINI_API_KEY`: Gemini API 키. **GitHub에 올리지 마세요.**
   - `APP_PIN`: 16자 이상 추측하기 어려운 비밀번호. 로그인 화면에서 같은 값을 입력합니다.
   - `GEMINI_MODEL`: 선택 (예: `gemini-2.5-flash`)
4. 환경변수 저장 후 **새 배포(Redeploy)** 합니다.
5. 배포 주소를 시크릿 모드로 열어 첫 화면이 `/login.html`로 바뀌는지 확인하세요.
6. 틀린 비밀번호는 거절되고, 맞는 비밀번호로만 앱이 열리는지 확인하세요. 로그아웃 이후도 재확인하세요.

## 알아둘 사항
- 이 잠금은 앱 콘텐츠 및 Gemini API에 대한 **서버 측 접근 제어**입니다. 소스 파일 자체가 공개 저장소에 있다면 코드는 여전히 공개됩니다.
- 기록은 원격 DB가 아닌 **브라우저 localStorage**에 저장됩니다. 같은 휴대폰·같은 도메인에서만 자동으로 나타나며, 브라우저 데이터를 삭제하면 사라집니다.
- 공유 기기에서는 브라우저 프로필이나 개발자 도구를 통해 로컬 기록을 볼 수 있으니 주의하세요. 휴대폰 잠금도 사용하세요.
- Vercel 자체 서비스 운영자, 브라우저에 접근한 사람, Gemini API 처리자까지 완전히 차단하는 종단간 암호화가 아닙니다.
- 서버리스 단일 PIN 인증에는 완전한 속도 제한이 없으니 **긴 무작위 비밀번호를 사용**하고, Vercel WAF 설정 등을 고려하세요.
- 기존 APP_PIN을 바꾸면 기존 로그인 쿠키가 무효화됩니다.


## 빠른 즉석 장면 모드 (업데이트)
- 기본 모델: `gemini-2.5-flash` (사용 중인 Gemini 2.5 계열). 모델 접근 권한이 없으면 Vercel의 `GEMINI_MODEL`을 본인 프로젝트에서 사용 가능한 모델로 바꿔 주세요.
- 목표 기본 500자. 본문만 출력하고 서론/해설/불필요한 문학적 장식을 피하도록 프롬프트를 조정했습니다.
- 이전 메시지는 최대 8개만 전달해 요청 시간을 줄입니다. 복잡한 장기 문맥의 정확도는 낮아질 수 있습니다.
- 조절 가능한 Gemini 안전 필터 4개는 `OFF`로 요청합니다. Google의 해제 불가능한 기본 안전 정책은 계속 적용되며, 서비스 정책에 따라 응답이 차단될 수 있습니다.
- Vercel 환경변수에 `GEMINI_MODEL`이 `gemini-2.5-flash`로 설정하거나 기존 2.5 설정을 유지하세요.

## 다크모드와 글자 크기 (추가)
- 사이드바의 `화면 설정` 또는 상단의 `◐ 화면` 버튼에서 라이트/다크 모드를 전환할 수 있습니다.
- 채팅 본문과 입력창의 글자를 **12~24px**로 키우거나 줄일 수 있습니다.
- 환경설정은 대화 데이터와 별도의 localStorage 키에 저장되어 페이지 재방문 시 유지됩니다.
- 기본 Gemini 모델은 `gemini-2.5-flash`입니다. Vercel `GEMINI_MODEL` 환경변수가 있다면 그 설정이 우선 적용됩니다.
